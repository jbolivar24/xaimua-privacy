Xaimua Car Launcher

Política de Privacidad

Última actualización: 3 de julio de 2026

Xaimua Car Launcher respeta la privacidad de sus usuarios. Esta política explica qué permisos utiliza la aplicación, cómo se procesan los datos y cómo se protege la información.

Información que recopilamos

Xaimua Car Launcher no recopila información personal como nombre, correo electrónico, ubicación, fotografías, contactos o mensajes.

La aplicación funciona principalmente procesando información de manera local en el dispositivo del usuario.

Permisos utilizados

La aplicación puede solicitar los siguientes permisos para proporcionar sus funciones:

Bluetooth

Se utiliza para buscar, conectar y comunicarse con adaptadores OBD2 y otros dispositivos Bluetooth compatibles.

Ubicación

En determinadas versiones de Android, el sistema requiere permisos de ubicación para realizar el escaneo de dispositivos Bluetooth. Xaimua Car Launcher no utiliza estos permisos para rastrear ni almacenar la ubicación del usuario.

Notificaciones

Si el usuario habilita el acceso a las notificaciones, Xaimua Car Launcher utiliza este acceso únicamente para identificar la canción que se está reproduciendo, obteniendo el título de la canción y el nombre del artista para mostrarlos en la interfaz del launcher. Esta información se utiliza únicamente para proporcionar la función de información musical y permanece en el dispositivo. Xaimua no recopila, almacena ni transmite estos datos a servidores externos.

Acceso a Internet

La aplicación utiliza acceso a Internet únicamente cuando es necesario para funciones propias de la aplicación, como comprobar conectividad o acceder a servicios relacionados con Xaimua. No se utiliza para recopilar información personal del usuario.

La aplicación no utiliza el acceso a Internet para recopilar ni transmitir información personal del usuario, salvo cuando sea necesario para prestar una función solicitada por el propio usuario.

Almacenamiento de datos

Las preferencias de configuración y los datos necesarios para el funcionamiento de la aplicación se almacenan localmente en el dispositivo.

Compartición de datos

Xaimua Car Launcher no vende, comparte ni transfiere información personal a terceros.

Seguridad

Se adoptan medidas razonables para proteger la información almacenada localmente en el dispositivo. Sin embargo, ningún sistema puede garantizar una seguridad absoluta.

Cambios en esta política

Esta Política de Privacidad podrá actualizarse cuando sea necesario para reflejar cambios en la aplicación o en la legislación aplicable. La versión más reciente estará disponible en esta página.
