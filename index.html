Política de Privacidad

Última actualización: 30 de octubre de 2026

Xaimua respeta la privacidad de sus usuarios. Esta política explica cómo funcionan Xaimua Car Launcher y Xaimua Unlocker, qué información utilizan y cómo se protege.

Aplicaciones cubiertas

Esta política se aplica a Xaimua Car Launcher y Xaimua Unlocker. Cada aplicación utiliza únicamente la información necesaria para proporcionar sus funciones.

Información que recopilamos

Xaimua Car Launcher no recopila información personal como nombre, correo electrónico, ubicación precisa, fotografías, contactos o mensajes para sus funciones habituales. La aplicación procesa principalmente información de manera local en el dispositivo.

Xaimua Unlocker está diseñado para comprobar la legitimidad de la licencia de la aplicación mediante los servicios de licencias de Google Play. La comprobación puede implicar el intercambio de datos técnicos de licencia e información necesaria para que Google determine si la aplicación está autorizada. Xaimua no recibe los datos de pago ni los datos completos de la cuenta de Google del usuario a través de esta comprobación.

Google puede procesar información de acuerdo con sus propias políticas y condiciones de servicio. Para más información, consulta la Política de Privacidad de Google.

Permisos utilizados por Xaimua Car Launcher

La aplicación puede solicitar los siguientes permisos para proporcionar sus funciones:

Bluetooth

Se utiliza para buscar, conectar y comunicarse con adaptadores OBD2 y otros dispositivos Bluetooth compatibles.

Ubicación

En determinadas versiones de Android, el sistema requiere permisos de ubicación para realizar el escaneo de dispositivos Bluetooth. Xaimua Car Launcher no utiliza estos permisos para rastrear ni almacenar la ubicación del usuario.

Notificaciones

Si el usuario habilita el acceso a las notificaciones, Xaimua Car Launcher puede identificar la canción que se está reproduciendo, obteniendo el título y el nombre del artista para mostrarlos en la interfaz. Esta información se utiliza para esa función y permanece en el dispositivo; no se transmite a servidores de Xaimua.

Acceso a Internet

Xaimua Car Launcher utiliza Internet cuando es necesario para funciones propias de la aplicación o para acceder a servicios relacionados con Xaimua. No utiliza este acceso para recopilar información personal ajena a esas funciones.

Xaimua Unlocker y verificación de licencia

Xaimua Unlocker permite comprobar si la licencia de Xaimua Unlocker está reconocida por Google Play. Para ello, la aplicación se comunica con el servicio de licencias de Google Play cuando el dispositivo dispone de conexión a Internet.

Para permitir el funcionamiento sin conexión, la aplicación puede conservar localmente el resultado y los datos técnicos mínimos necesarios para recordar la última autorización válida y evaluar su vigencia. Estos datos se utilizan exclusivamente para gestionar el acceso a las funciones Pro de Xaimua Car Launcher.

Cuando vuelve a haber conexión, la licencia puede comprobarse nuevamente con Google Play y actualizarse la autorización local. Si no es posible confirmar la licencia durante el período permitido, el acceso a las funciones Pro puede suspenderse hasta completar una nueva verificación satisfactoria.

La información local de autorización no se utiliza para publicidad ni para crear perfiles de usuario.

Almacenamiento de datos

Las preferencias de configuración y los datos necesarios para el funcionamiento de las aplicaciones se almacenan localmente en el dispositivo. Xaimua Unlocker conserva únicamente la información técnica de licencia necesaria para administrar la autorización sin conexión.

Compartición de datos

Xaimua no vende información personal. La comprobación de licencias de Xaimua Unlocker requiere la comunicación con los servicios de Google Play, que procesan la información necesaria para responder a la solicitud de licencia conforme a sus propias políticas.

Seguridad

Se adoptan medidas razonables para proteger la información almacenada localmente en el dispositivo y limitar su uso a las funciones descritas en esta política. Sin embargo, ningún sistema puede garantizar una seguridad absoluta.

Cambios en esta política

Esta Política de Privacidad podrá actualizarse cuando sea necesario para reflejar cambios en las aplicaciones, en los servicios utilizados o en la legislación aplicable. La versión más reciente estará disponible en esta página.
